# scopes2 adapteri

Huom: tekstin polut `scopes2/...` ovat alkuperäisen monorepon etuliite; tässä repossa ne alkavat repon juuresta (esim. `node adapteri/adapteri.mjs`). Adapteri on tässä repossa; osa sen testeistä ja `vertailu/`-skripteistä tarvitsee kuitenkin monorepon `claude/siirto/tools/`- ja `scopes/`-hakemistoja (V1).

Peilaa Claude Coden transkriptit (`~/.claude/projects/**/*.jsonl`) scopes2-ytimeen (S-5a). Vanhaa palvelua
(`scopes/`) vain luetaan ja tuodaan (`import`), sitä ei muuteta (K-9, P-9).

```
node scopes2/adapteri/adapteri.mjs [--ydin url] [--projektit ~/.claude/projects] [--istunnot <istunnotDir>] [--kerran]
```

- `--ydin`: oletus `$SCOPES2_YDIN` tai `http://127.0.0.1:8797`. Avain: `~/.config/scopes2/avain` (luetaan käynnistyksessä ja 401:n jälkeen).
- `--istunnot`: seuraa vain elävien istuntojen transkripteja (sekä `fs.watch`in ilmoittamia); ilman sitä kaikkia `*.jsonl`-tiedostoja.
- `--toiminnot <portti>` (T-63-G, S-10): kuuntelee lisäksi `127.0.0.1:<portti>` ARK-16:n toimintoreiteille (Bearer = V2-avain); ilman lippua ei kuuntele. `kaynnista.sh` antaa lipun, kun `SCOPES2_TOIMINNOT` on asetettu (tuotanto 8798, koe 18822).
- `--kerran`: yksi kierros; exit 0 = kaikki lähetetty, 1 = rivejä jäi jonoon tai ydin ei vastannut.
- Loki stderr:iin: `peili <tiedosto> +<rivit> → <offset>` per lähetys. Avainta ei lokiteta.

## Tiedostot

- `transkriptit.mjs`: `lueLisays` (vain uudet kokonaiset rivit, vajaa rivi odottaa, lyhentynyt tiedosto → `nollattu`), `istuntotiedostot` (elossa-tarkistus `/proc/<pid>/stat`).
- `peili.mjs`: `luoPeili` → `laheta`, `kasittele` (409 → ytimen offset → luku sieltä), `alusta` (GET offset), `pura` (jonon uusinta 5 s), `jono`, `sulje`. `sha256` = hex-tiiviste rivien tavuista rivinvaihtoineen (`rivit.map(r => r + '\n').join('')`).
- `gate.sh <ID> | --itsetesti`: testit (T-24: transkriptit + peili; T-29: lahde) ja aidat lähtötilaan verrattuna: ajon aikana ilmestynyt muutos `scopes/`-alla (`VANHA PUU MUUTTUNUT`) tai `GATE_MAY`-etuliitteiden (oletus `scopes2/adapteri/`) ulkopuolella → exit 2. Jo ennestään olemassa olevat muutokset eivät punaa porttia.
- `toiminnot/`: toimintokuuntelija (S-10). `palvelin.mjs` (`luoToimintopalvelin`: tunnistus, `GET /api/terveys` ilman avainta → `{ok, adapteri, reitit}` vain toteutetuista, 401, toteuttamaton ARK-16-reitti 501 `ei siirretty`, muu polku 404), `reitit.mjs` (kokoaa moduulien `REITIT` ja sovittaa kuviot: `*` = yksi polun osa, loppu `/**` = etuliite), `runko.mjs` (`vastaa`, `lueRunko`, `kirjoitaNdjson`, `tyhja`), `aja.mjs` (kopio `scopes/palvelu/toiminnot.mjs:32-73`: `ajaKomento`, `Hylatty` …) ja moduulit `viestit` (T-66), `istunto` (T-67), `pura` (T-68), `chat` (T-69), joiden `REITIT`-rivi vaihtaa `toteutettu: true`. Moduulin rajapinta: `{ metodi, kuvio, toteutettu, kasittele(req, res, osat, ymp) }`, `ymp = { aja, juuri, tila, loki, kello }`. Oma tila `~/.local/state/scopes2/toiminnot.loki`.
- `vertailu/tallenna-vanha.mjs`: ajaa vanhan `luoViestit`/`luoToiminnot` tallentavalla mock-`aja`lla ja kirjoittaa fixturet `testidata/toiminnot/<reitti>-<tapaus>.json` (ainoa adapterin tiedosto, joka saa tuoda `scopes/`-polusta; poistetaan vanhan alasajossa). Ajetaan käsin, ei portissa: `node scopes2/adapteri/vertailu/tallenna-vanha.mjs`. `testidata/tmux-mock/` = tmux-, autovaihto-, pura-malliton-, claude- ja ssh-mockit testeille (`TMUX_MOCK_LOKI` kirjaa argv:t, `TMUX_MOCK_DATA` antaa vastaukset).
- `vertailu/tallenna-lisa.mjs` (T-79-G): sama lisäreiteille (`malli`, `uusi`, `agentit`, `asetukset`, `android`, `linux`; ARK-16:n loput ja ARK-19). Ajaa vanhan `kasittelija`n in-process, `luoViestit`/`luoToiminnot`/`luoAsetukset`/`luoIstuntoValinta`/`luoAndroid`/`luoLinuxServer` mock-`aja`lla (ei adb:tä, pingiä, WoL:ia, ssh:ta, tmux:ia eikä verkkoa) ja kirjoittaa `testidata/toiminnot/{malli,uusi,agentit,asetukset,android,linux}-<tapaus>.json` (T-63-G:n fixtureihin ei kosketa). Ajetaan käsin, ei portissa: `node scopes2/adapteri/vertailu/tallenna-lisa.mjs`; uudelleenajo ei saa muuttaa fixtureja (`git diff scopes2/adapteri/testidata/toiminnot` tyhjä). Fixturemuoto = T-63-G:n sekä lisäksi `pyynto.runko` merkkijonona = raakarunko (android/liite), `ymparisto.tmux["capture-pane"]` taulukkona = peräkkäiset vastaukset, `ymparisto.komennot.vastaukset` = `[{ komento, sisaltaa?, koodi?, stdout?, stdoutBase64?, stderr?, jarjestys? }]` (adb, python3, ping, ssh, agy, git, bash, node), `samanaikainen.pito` = komento, jossa ensimmäinen pyyntö pidetään (linux: `python3`), `asetuksetTila`/`odotus.asetuksetTila` = kytkinten tilahakemiston tiedostot, `androidMukana`, `nebiusAvain`, `android`/`linux` `{ kuiva, myohemmin }`; binäärivastaus `odotus.runko = { tyyppi, base64, nimi? }`; lisäpaikkamerkit `<REPO>` (herata-pc.py), `<ANDROID>`, `<LIITTEET>`. Mockit samassa `testidata/tmux-mock/`-hakemistossa: `adb`, `ping`, `python3` ja laajennettu `ssh` (`<avain>.json`-säännöt, kts. `mock-saannot.mjs`; ilman .json:ia vanha `ssh.txt`-käytös).
- `gate.sh` T-63, T-65…T-69: toimintoportin testit (testien portti `GATE_TOIMINTOPORTTI`, oletus 18822); T-65 vertaa `vanhasta/`-kopiot alkuperäisiin; kaikissa tapauksissa tuontitarkistus (`TUONTI: <rivi>`, exit 1; `vertailu/` rajattu pois; sallitut poikkeukset listassa `SALLITUT_TUONNIT`, jonka T-65 tyhjentää).
